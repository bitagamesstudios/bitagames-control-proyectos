# BitaGames Studios · Control de proyectos

Tablero Kanban (un solo archivo HTML) para controlar los proyectos que generan ingresos y suman a la hoja de vida.

- **Uso diario (PC + iPhone sincronizados):** https://claude.ai/artifact/TNswrthAEr1Gy9ke3msieL
- **Bitácora en Notion:** https://app.notion.com/p/3fcb9b60077b81128fadce6e26275891
- **Versión:** v2.4 (24-sep-2026)

## Cómo funciona
- Publicado como artefacto de Claude: los datos se guardan en la cuenta (capacidad `db`) y se sincronizan entre dispositivos.
- Abierto como archivo local (`index.html`), guarda solo en ese navegador (`localStorage`).

## Funciones
Lista de espera con pegado masivo y selección múltiple · columnas por estado con arrastre · prioridad y puntaje sugerido · cliente, valor, mensualidad y recursos · bitácora automática · alertas de fechas · buscador y filtros · pestaña Hoja de vida · Completar con IA · tema claro/oscuro.

## Archivos
- `index.html` — el tablero completo.
- `assets/` — logo e ícono para iPhone.
- `CHANGELOG.md` — historial de versiones.
